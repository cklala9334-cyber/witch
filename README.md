# 소녀마법사랑 별빛 달리기

프로젝트 루트의 `index.html`이 게임 실행 진입점입니다. 프로젝트 폴더를 열고 루트 HTML을 실행하면 게임이 바로 열립니다.

게임 본체와 에셋은 [`witch-cat-runner`](./witch-cat-runner/) 폴더에 보존되어 있습니다.

두 번째 게임은 [`demon-village-runner`](./demon-village-runner/)에서 실행할 수 있습니다.

## 조작

- `Space` / `↑` / 화면 탭: 점프
- `P`: 일시정지

## GitHub Pages

GitHub Pages workflow는 게임 본체를 사이트 루트로 배포하므로 배포 후에는 별도 하위 폴더 없이 게임이 표시됩니다.
