# 소녀마법사랑 별빛 달리기

작은 마법사와 동료가 숲길을 달리는 한국어 2D 브라우저 게임입니다.

## 조작법

- `Space` / `↑` / 게임 화면 터치: 소녀마법사의 덤블링 점프
- `Shift`를 누르고 있는 동안 빠르게 달립니다. 화면의 `속도 높이기` 버튼을 누르고 있어도 됩니다.
- `P`: 일시정지
- `X` 또는 `고양이 마법` 버튼: 별을 3개 모아 선택한 마법을 사용합니다.
- `오늘의 마법 고르기`에서 별빛·꽃·달빛 중 하나를 선택할 수 있습니다. 꽃은 하트와 보호막을 회복하고, 달빛은 잠시 속도를 늦춥니다.
- 바위와 가시를 뛰어넘습니다. 가까스로 피하면 추가 점수를 받습니다. 버섯고양이는 각 구간에서 한 번 위험을 막아줍니다.
- 별은 위아래로 움직이며, 드물게 높은 위치의 푸른 별이 나타납니다.
- 행운의 여신을 만나면 진행이 멈추고 현재 체력에 따라 하트·보호막 회복 또는 500점 보너스를 고릅니다.
- 모바일에서는 게임 화면 터치와 점프, 속도 높이기, 고양이 마법 버튼을 사용할 수 있습니다.

## 모험과 기록

- 별의 숲, 달빛 계곡, 별빛 정원을 지나 별빛을 되찾는 세 구간 모험입니다.
- 사라진 별빛을 찾는 소녀마법사와 버섯고양이의 짧은 이야기로, 구간마다 배경과 안내 문구가 바뀝니다.
- 별의 숲·달빛 계곡·별빛 정원이 각기 다른 배경 이미지를 사용합니다. `장면 미리보기`를 누르면 세 장면을 차례로 볼 수 있습니다.
- 게임 방법은 화면 아래의 `게임 방법 보기`를 열어 확인할 수 있습니다.
- 별 5·10·20·30개 달성 시 꽃다발, 축하 폭죽 등의 선물이 지급됩니다.
- 참가자 이름을 입력하고 `기록 불러오기`를 누르면 그 이름의 최고 점수와 선물을 봅니다.
- 기록은 **현재 브라우저의 localStorage**에 저장됩니다. 다른 기기와 공유되지 않으며, 브라우저 데이터를 지우면 사라집니다.

## 로컬 실행

정적 파일이므로 폴더를 웹 서버로 열면 됩니다.

```bash
cd witch-cat-runner
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 여세요. `file://`로 직접 열어도 대부분 동작하지만, 웹 서버를 사용하는 편이 이미지 로딩과 배포 환경을 정확히 확인할 수 있습니다.

## GitHub Pages 배포

저장소의 `witch-cat-runner` 폴더를 Pages 사이트 루트로 배포하도록 GitHub Actions가 구성되어 있습니다.

1. 저장소의 `Settings → Pages`에서 **Source: GitHub Actions**를 선택합니다.
2. `witch-cat-runner` 폴더의 파일을 커밋하고 `main` 브랜치에 push합니다.
3. `Actions` 탭의 Pages 배포가 끝나면 사이트 URL을 엽니다.

게임은 서버 API나 빌드 단계가 없는 정적 사이트라서 별도 의존성 설치가 필요 없습니다.
